Banner

Test page for the Web Monetization Publisher Tools banner.

This page embeds the banner from the Web Monetization Publisher Tools. The banner invites visitors without the Web Monetization extension to install it, and should show up based on its configuration once the page has loaded.

URL parameters

You can customize the injected script by using these URL parameters:

Source of script: can be one of 'prod', 'staging', 'local', or a Pull Request number. This parameter is required.

Wallet address that receives the payments. The banner config is fetched with this wallet address as key.
